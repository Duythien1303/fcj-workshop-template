### Achievements in Week 1

#### 1. Knowledge of Cloud Computing

- Gained an understanding of Cloud Computing and its fundamental benefits, including scalability, flexibility, and resource optimization.
- Learned to distinguish between the three main cloud service models:
  - **IaaS (Infrastructure as a Service):** Provides infrastructure resources such as servers, networking, and storage.
  - **PaaS (Platform as a Service):** Provides a platform for developing and deploying applications.
  - **SaaS (Software as a Service):** Delivers software applications as services over the Internet.
- Understood the differences between Public Cloud, Private Cloud, and Hybrid Cloud.

#### 2. General Knowledge of AWS

- Developed a fundamental understanding of Amazon Web Services and its role in providing cloud computing services.
- Explored commonly used AWS service categories:
  - **Compute:** Amazon EC2, AWS Lambda.
  - **Storage:** Amazon S3, Amazon EBS.
  - **Database:** Amazon RDS, Amazon DynamoDB.
  - **Networking:** Amazon VPC, Amazon Route 53.
  - **Security:** AWS Identity and Access Management (IAM).

#### 3. Knowledge of AWS Infrastructure and Security

- Understood the concepts of AWS Regions and Availability Zones.
- Recognized the role of Edge Locations in content delivery.
- Studied the AWS Shared Responsibility Model and the security responsibilities shared between AWS and its customers.

#### 4. Familiarization with the AWS Environment

- Explored the AWS Management Console interface and how AWS services are organized within the platform.
- Became familiar with fundamental concepts related to resource management, access permissions, and deployment regions.
- Recognized the importance of account security and cost management when using AWS services.

#### 5. Week 1 Summary

The first week focused on building a foundational understanding of Cloud Computing and Amazon Web Services while becoming familiar with the learning objectives and overall direction of the internship program.

Throughout the week, I explored cloud service models, AWS service categories, global infrastructure, and fundamental security concepts. These activities helped me establish a basic understanding of how cloud technologies support modern IT systems.

The knowledge acquired during Week 1 will serve as a foundation for further exploration of AWS services, particularly Networking, Security, Storage, and Database technologies in the following weeks.
