## 2. Purpose of the Event

The **Buildrathon Kickoff: Code the Future with CMC Global** event aimed to connect technology enthusiasts, introduce the Buildrathon 2026 challenge, and provide opportunities to explore emerging trends in Cloud Computing and Artificial Intelligence.

The key objectives included:

- **Expanding Technical Knowledge:** Exploring developments in Cloud Computing, Generative AI, and Agentic AI.
- **Introducing Buildrathon:** Understanding the challenge objectives, solution development process, and evaluation criteria.
- **Exploring Real-World Applications:** Learning how organizations utilize AWS and AI Agents to solve technical and business problems.
- **Developing Practical Skills:** Becoming familiar with Prompt Engineering, Retrieval-Augmented Generation (RAG), Knowledge Bases, and AI Agent architectures.
- **Exploring Career Opportunities:** Understanding professional roles and essential skills in Cloud Computing and AI.
- **Building Professional Connections:** Encouraging knowledge sharing and interaction among students, technology enthusiasts, and industry professionals.

### 3.3. Hands-on: AI Agent Challenge

The event program included a hands-on activity focused on developing AI Agent applications.

The technical topics introduced included:

**Prompt Engineering**

The process of designing and optimizing instructions to improve the effectiveness of interactions with Large Language Models (LLMs).

**Retrieval-Augmented Generation (RAG)**

An approach that combines information retrieval from external data sources with the text-generation capabilities of language models.

**Knowledge Bases**

Structured collections of information that support knowledge retrieval and provide relevant context for AI applications.

**AI Agents**

AI-powered systems that combine language models with external tools, APIs, and automated workflows to perform tasks.

### 3.4. Exploring a Real-World AI Agent Architecture

One of the technical presentations demonstrated an AI Agent architecture integrated with Slack and several automation components.

The architecture included:

- **Slack:** A communication platform used to submit requests and interact with the system.
- **Socket Mode:** A WebSocket-based mechanism for receiving Slack events.
- **Response Gate:** A component responsible for controlling responses within communication channels.
- **Claude Code:** An AI-powered component supporting task execution and development workflows.
- **SOUL.md:** A configuration file defining the agent's role and behavioral instructions.
- **Memory:** A component responsible for maintaining relevant information and context.
- **Internal API:** An interface that enables communication with internal services.
- **Cron and Database:** Components supporting scheduled tasks and data storage.

The architecture illustrated how different software components can work together to build an integrated AI automation system.
